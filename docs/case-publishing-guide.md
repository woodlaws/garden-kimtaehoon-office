# 업무 사례 게시·교체 기준

현재 `data/case-examples.ts`의 콘텐츠는 모두 일반적인 상황을 바탕으로 만든 `example`입니다.

실제 수행 자료로 교체할 때는 다음 조건을 모두 확인한 뒤에만 `type: "case"`로 변경합니다.

1. 김태훈 행정사의 실제 수행 여부를 내부 자료로 확인합니다.
2. 공개 범위와 목적에 관해 의뢰인의 명시적 동의를 확인하고 `consentConfirmed: true`로 변경합니다.
3. 사실관계와 표시할 진행 내용을 검증하고 `actualCaseVerified: true`로 변경합니다.
4. 이름, 회사명, 주소, 연락처, 사건번호, 등록번호, 여권번호, 계좌정보, 문서번호, 정확한 날짜 등 개인이나 사건을 식별할 수 있는 정보를 삭제하거나 범주화합니다.
5. 여러 정보의 조합으로 당사자를 알아볼 수 없는지 재식별 가능성을 검토합니다.
6. 승인·승소·성공률·처리기간·결과 보장처럼 오인될 표현과 고객 후기는 별도 사실·동의 확인 없이 게시하지 않습니다.
7. 공개 후 철회 요청에 대응할 담당자와 삭제 절차를 확인합니다.

목록과 상세 페이지는 데이터 파일을 읽어 자동 생성되므로, 검수를 마친 레코드를 추가하거나 기존 예시 데이터를 교체하면 됩니다.
